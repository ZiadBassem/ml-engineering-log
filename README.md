# ml-engineering-log

My public practice log on the way to becoming an ML engineer for industrial and energy systems.

**[Proof wall →](PROOF.md)** — everything I've finished, with dates and links. Updated automatically.

Every entry here was:

1. solved from a blank file in a timed session, without notes;
2. reviewed, then corrected until it passed (each entry keeps its attempt history);
3. written up with the key insight and what I got wrong first;
4. scanned for secrets before it was pushed.

## Layout

- `practice/blind/`: daily blind solves (original problems)
- `practice/neetcode/`: NeetCode 150 problems, also submitted on NeetCode ([neetcode-submissions](https://github.com/ZiadBassem/neetcode-submissions))
- `practice/concepts/`: ML, statistics and systems concept drills

The full list is in [`practice/README.md`](practice/README.md).
